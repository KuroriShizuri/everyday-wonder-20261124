One sentence, 132 characters, that makes a small everyday moment feel strange and new: a neighbour's radio plays the song from the narrator's seventh birthday, and for one chorus the whole stairwell forgets which decade it is in.

> My neighbour's radio played the song from my seventh birthday, and for one chorus the whole stairwell forgot which decade it was in.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` (Python standard library only, deterministic, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with no trailing newline, validates it against the gate — 1 to 200 characters, a single line, not only white space — and reads it back to confirm the file holds exactly the entry. `--check` validates without writing; `--self-test` validates and verifies a byte-identical write/read round-trip in a temporary directory.
